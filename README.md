# Diabetes-Prediction-using-FFNN

This project uses a Feed Forward Neural Network (FFNN)
to predict diabetes using the Pima Indians Diabetes Dataset.

## Technologies Used
- Python
- TensorFlow
- Keras
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Data preprocessing
- FFNN model training
- Accuracy and Loss graphs
- Diabetes prediction

## Dataset
Pima Indians Diabetes Dataset
